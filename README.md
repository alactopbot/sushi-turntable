# 寿司拼盘 · 经典消消乐 v3

交换旁边的寿司，连成三个就消掉。掉下来的还能再连哦。

Vite + TypeScript + DOM 棋盘与本地 SVG 寿司皮肤，纯静态，手机竖屏可玩。

- 固定 8×8，开局无三连；点击两块正交相邻寿司交换。无效交换弹回、不扣步；有效交换扣一步。
- 横竖连续 ≥3 整段同时清除，上方下落，顶部按本关前 N 种寿司随机补齐，直到稳定。同次连锁不另扣步。
- 每段计分 `60 × (长度 − 2)`：3=60、4=120、5=180、6=240。第 n 轮所有段得分乘 n；交叉的横竖段分别计分，交点只清除一次。无特殊块。
- 达到目标即过关；结算后步数用尽且未达目标则失败。不以无合法步为失败条件，也不自动洗牌。
- 下一关、重试均无需刷新；第五关完成后可从第一关再玩。

| 关 | 棋盘 | 种类 | 步数 | 目标分 |
|---|---|---|---|---|
| 1 | 8×8 | 4 | 30 | 800 |
| 2 | 8×8 | 5 | 26 | 1400 |
| 3 | 8×8 | 5 | 24 | 2000 |

## 运行与验证

Node.js 20.19+：

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`src/game.ts` 是可注入随机数的纯引擎，返回各轮清除、重力、补位快照；`src/levels.json` 是关卡表。`src/main.ts` 展示交换、弹回、消除、下落与连锁飘分，结算期间锁定输入。

规则测试验证计分、正交交换、稳定开局、重力补位、连锁步耗与胜负。Playwright 用桌面点击和手机触屏验证文案、交换、五关推进、失败与不刷新重试。开发环境提供只读 `window.__sushi` 快照；仅开发环境带 `?e2e` 时提供测试局面装载入口，生产构建不含入口。真实设备触控舒适度仍需人工试玩。
