# 验收标准 · 转转寿司（流水线 v2）

对照 `one-pager.md` v2.1 与 `PRODUCT.md`。逐条：**通过/失败** + 复现。禁止不可测手感项。  
**挡版**：主路径不得再是圆桌交换。

## 冒烟

| ID | 标准 | 如何验证 |
|----|------|----------|
| S1 | URL 可开，无白屏/持续报错挡操作 | 桌面+手机各一次 |
| S2 | 能完成一关：取餐→≥1 次三消→胜或负结算 | 胜、负各一 |
| S3 | 胜/负可区分；可重试；过关可进下一关（或关 1 循环到关 2） | 各触发一次；分/盘重置 |
| S4 | 重试无需整页刷新 | 连开两局 |
| S5 | 仅触控可玩完一关 | 不用键盘 |

## 核心规则（挡版）

| ID | 标准 | 如何验证 |
|----|------|----------|
| R1 | 主操作=点流水线寿司入**盘尾**；非圆桌换格 | 实机无「两格交换」主操作 |
| R2 | 盘内不可重排 | 尝试拖换应无效 |
| R3 | 连续同款 ≥3 消除；清除后两端拼接可再消 | 构造拼接连锁至少一次 |
| R4 | **3 消=60，4 消=120**（5=180）；4 分明显高于 3 | 各造一次看飘分 |
| R5 | 盘满且无法 ≥3 消 → 失败 | 故意塞满杂款 |
| R6 | 达目标分 → 本关胜利 | 打到目标 |
| R7 | ≥5 关可进；关 1 盘格 8/种类 3/目标 180（或与表一致） | 对照一页纸表与 HUD |
| R8 | 高关比关 1：盘更紧或种类更多或线更绕（至少两项可感知） | 关 1 vs 关 3 或 5 |
| R9 | 可点线上任意可见寿司（非仅最前端） | 点中段一枚可取 |
| R10 | 溜到终点未取的寿司回收，不直接判负 | 放任一枚走完 |

## 可接受 / 阻塞

- 可接受：简陋路径美术、无音效、关卡数值需微调（只改表）。
- 阻塞：圆桌回流、可盘内重排、无 3/4 分差、无盘满失败、不足 5 关骨架。
