# 验收标准 · 寿司拼盘（经典消消乐 v3）

对照 `one-pager.md` v3 与 `PRODUCT.md`。逐条：**通过/失败** + 复现。禁止不可测手感项。  
**挡版**：主路径必须是棋盘相邻交换；**不得**再是流水线点餐入盘或圆桌环槽。

## 冒烟

| ID | 标准 | 如何验证 |
|----|------|----------|
| S1 | URL 可开，无白屏/持续报错挡操作 | 桌面+手机各一次 |
| S2 | 能完成一关：交换→≥1 次三消→胜或负结算 | 胜、负各一 |
| S3 | 胜/负可区分；可重试；过关可进下一关 | 各触发一次；分/步/盘重置 |
| S4 | 重试无需整页刷新 | 连开两局 |
| S5 | 仅触控可玩完一关 | 不用键盘 |

## 核心规则（挡版）

| ID | 标准 | 如何验证 |
|----|------|----------|
| R1 | 主操作=交换**正交相邻**两格；非点流水线入盘、非圆桌换槽 | 实机无流水线/盘子主操作 |
| R2 | 无效交换（消不成）弹回且**不扣步** | 故意换两非连块 |
| R3 | 有效交换后横/竖 ≥3 同款消除 | 造一次三消 |
| R4 | 消除后上方下落，顶部补新块；可触发连锁 | 至少一次下落后再消 |
| R5 | **3=60 / 4=120 / 5=180**；连锁段序有倍数 | 各造一次看飘分 |
| R6 | 达目标分 → 胜利（可剩余步） | 打到目标 |
| R7 | 步数用尽且未达分 → 失败 | 耗尽步数 |
| R8 | ≥5 关可进；关 1 为 8×8 / 种类 4 / 步 30 / 目标 800（或与表一致） | 对照一页纸表与 HUD |
| R9 | 高关比关 1：种类更多或步更紧或目标更高（至少两项可感知） | 关 1 vs 关 3 或 5 |
| R10 | 开局稳定盘（无未处理的开局三连甩给玩家） | 新开 3 局检查 |

## 可接受 / 阻塞

- 可接受：简陋粒子/无音效、关卡数值需微调（只改表）、特殊块未做。
- 阻塞：流水线/盘子回流、无重力随机补块、无连锁、无 3/4 分差、无步尽失败、不足 5 关骨架、主操作不是相邻交换。
